A pure-Python (standard library only) program that draws a newspaper front page summing up the world news of Wednesday 18 November 2026: NVIDIA's Q3 results, Anthropic's IPO pricing, OpenAI's GPT-6.2, World Cup qualifiers, US energy storage and Korea's satellite SiC chip. It renders its own bitmap type and writes a deterministic 1024x1024 PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
